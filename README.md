# Python Estudos

Repositório criado para armazenar exercícios e projetos desenvolvidos durante meus estudos de programação em Python.

## Projetos

### Calculadora
Realiza operações matemáticas básicas:
- Soma
- Subtração
- Multiplicação
- Divisão

Arquivo: `calculadora.py`

### Gerador de Senhas
Gera senhas aleatórias utilizando:
- Letras maiúsculas e minúsculas
- Números
- Caracteres especiais

Arquivo: `gerador_senhas.py`

## Tecnologias Utilizadas

- Python 3

## Objetivo

Praticar lógica de programação e desenvolver habilidades em Python durante a graduação em Segurança da Informação.
